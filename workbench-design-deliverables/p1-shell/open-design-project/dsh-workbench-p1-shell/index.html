方向 A：原生延续型 (Native Continuation) 低视觉迁移成本

完全沿用现有 DSH Desktop 的平坦表面、紧凑间距和实色顶栏，仅通过新增的左侧导航项和右侧 Context 分组体现 Workbench 功能。

原生组件兼容性极高。直接复用 `--dsw-alias-bg-base` 与 `--dsw-specific-sidebar-fill`，零材质过渡成本。
视觉识别度较弱。Home 与全局 Context 看起来与普通设置列表接近，缺少 Workbench 工作台的空间层次。
信息密度与阅读舒适度紧凑（页面内边距 24–28px，分组间距 14px）。适合习惯高密度工具界面的用户，但 Home 呼吸感偏紧。
材质与毛玻璃策略顶栏与右栏头部均保持 100% 实色，仅在浮动菜单 (`--dsw-menu-surface-fill`) 保留原生半透明。
性能与无障碍回退无额外 GPU 合成开销；天然等同于实色回退状态。
实现成本与 Token 影响最小。几乎不新增材质 Token，仅需实现方案 B 的单轨布局仲裁。

方向 B：轻度产品化型 (Light Productized) 推荐方向 · 待用户批准

保留原生 Conversation、Terminal、Files 的 100% 视觉身份与实色高对比阅读面，同时在 Shell 顶栏、右栏仲裁头、Home 与 Context 建立清晰的空间节奏与克制毛玻璃层级。

原生组件兼容性高。绝不重绘 Conversation 消息流、Approval 卡、xterm 终端与文件树；原生区保持实色表面。
视觉识别度清晰且克制。通过顶栏局部毛玻璃 (`blur(14px)`)、Home 任务卡片层级与 Context 作用域徽标建立明确的产品识别。
信息密度与阅读舒适度分层密度：Home 与 Context 舒展（内边距 36px，分组间距 20px）；Terminal/Files/Code 保持原生紧凑行距。
材质与毛玻璃策略仅用于顶部轻量控制栏、右栏切换头、Popover 与抽屉遮罩；阅读区、代码、日志与危险操作确认强制实色。
性能与无障碍回退内置一键/自动实色回退 (`prefers-reduced-transparency` / 无 `backdrop-filter`)，正文对比度 ≥ 4.5:1。
实现成本与 Token 影响可控。复用原生 `ThemeRuntime`，仅补充 6 个受控材质/间距语义别名，不新建平行 Theme Runtime。
