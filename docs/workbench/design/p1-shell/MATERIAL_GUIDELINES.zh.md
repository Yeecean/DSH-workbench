# P1 Desktop 材质指南

[English](MATERIAL_GUIDELINES.md) | 中文

## 摘要

本提议仅在有助于区分层级的位置使用半透明材质，同时保持阅读区域稳定并提供不透明回退。生产实现前需要验证视觉效果和性能。

<a id="surface-placement"></a>
## 表面位置

可考虑使用玻璃的区域包括紧凑工具栏、浮动菜单或 Popover、抽屉遮罩、选定的导航表面和轻量 Context 控件。候选区域必须证明模糊能澄清层级，且不会遮挡下方内容。

Conversation 文字、Terminal、代码、日志、Diff、文件内容、密集表格和设置表单默认使用不透明或其他稳定阅读表面。危险操作、确认和错误需要明确边界，不能靠模糊传达重要性。

材质层数保持克制；避免堆叠大面积模糊，也避免在复杂动态画面上放置文字。优先使用现有语义 Token 和共享组件，不为各组件分别硬编码样式。阴影用于表达真正的浮动表面，不装饰每个面板。

<a id="contrast-and-fallback"></a>
## 对比度与回退

在每个半透明表面下方放置有代表性的浅色、深色和高对比内容，检查文字、图标、边框和焦点环。普通文字的目标对比度至少为 4.5:1，大文字和必要控件或焦点指示至少为 3:1，并明确适用的例外。测量两种外观下的实际渲染组合；单独检查不受背景影响的 Token 值不足以证明。

模糊不可用、代价过高，或操作系统提供且用户要求减少透明效果时，使用具有等效可读前景和可见边界的不透明语义表面。减少动态效果时移除非必要过渡。选中、禁用、焦点和错误状态还应使用形状、文字、轮廓或其他非颜色提示；不能仅依赖模糊表达状态。

<a id="spacing-and-density"></a>
## 间距与密度

对照现有主题值，为窗口边缘、列、分组、行和控件内边距定义语义间距，避免为各组件硬编码独立尺度。使用清晰的标题、正文和元信息层级，可读的行高与行宽，以及克制的圆角、边框和分隔线。

Home 与 Context 概览可以采用较宽的分组间距；Terminal 输出、文件列表、工具状态和表格保持紧凑行距。在与有内容界面相同的宽度和字号下检查空、加载与错误状态。字号缩放不能遮挡导航或操作标签。

<a id="windows-review"></a>
## Windows 评审

在 Windows Native Desktop 的明暗外观中比较玻璃与不透明示例。检查高 DPI、窗口缩放、长时间 Terminal 输出、具有代表性的 GPU 与合成器配置，以及可用的系统透明和动态效果偏好；记录设备、缩放比例、测量值与未测条件。

检查窄窗口下的键盘焦点、文字选择、滚动、菜单和屏幕阅读顺序。如果效果降低响应速度或可读性，应使用不透明材质，不把模糊视为强制要求。

-----

<a id="dev-note"></a>
## 开发备注

这些是设计要求，不代表现有主题已支持运行时模糊控制或平台偏好检测。
