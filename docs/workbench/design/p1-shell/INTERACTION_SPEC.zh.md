# P1 交互设计

[English](INTERACTION_SPEC.md) | 中文

## 摘要

拟议界面让导航、Session 工具和外观选择容易找到，同时保留原生行为。视觉原型模拟交互，不能证明服务或持久化行为已经存在。

## 导航与右栏

这是拟议的单轨状态模型，不是现有 API 或已验证实现。分别表达 Session 的逻辑展开状态和标签、当前可见轨道所有者（`Context`、`Session` 或 `None`）以及几何资格。隐藏 Session 位置不等于用户主动关闭；当前原生位置在 `canShow=false` 时可能折叠，并在清理时报告关闭（[SidebarRight.tsx:397–449](../../../../packages/client/ui-sidebar-right/src/client/shell/SidebarRight.tsx)）。详见[右栏 ADR](../../GLOBAL_RIGHTBAR_ADR.zh.md)。

| 事件与先前状态 | 拟议的可见所有者和转换 | 保留状态与焦点 |
|---|---|---|
| 进入 Home，无论是否有活动 Session | Context 已注册、启用且几何允许时默认占用；否则轨道为 `None`，并提供可访问的重新打开或不可用状态。 | 保留可能存在的 Session 选择和右栏状态；显示全局 Context，对缺失的 Session 数据提供清晰空状态。 |
| 进入 Conversation | 存在有效 Session、展开意图且几何允许时按原生默认显示 Session 栏；否则显示 `None`，等待符合条件的明确选择。 | 保留当前 Session；选择右栏不能附带创建或切换 Session。 |
| 在 Conversation 选择 Context | Context 占用同一轨道；Session 暂停呈现，而不是关闭。 | 保留 Session 标签、Pane、滚动位置、逻辑展开状态、首选宽度和可恢复焦点目标。 |
| 从 Context 选择 Session | 在同一轨道恢复符合条件的原生 Session 栏；不可用时解释原因并保留可触达操作。 | 恢复保留的标签、Pane、滚动位置和宽度；若原焦点目标仍存在则恢复，否则聚焦有名称的右栏切换控件。 |
| 从 Conversation 返回 Home | Context 成为默认且符合条件的所有者；原生 Session 全屏呈现在 Home 暂停。 | 保留 Session 逻辑状态和显式全屏意图；不能让原生右栏覆盖 Home。 |
| 关闭可见右栏 | 将可见所有者设为 `None`，释放轨道和拖动手柄。 | 关闭当前所有者不能清除另一所有者的逻辑状态；焦点返回触发控件或可见的有名称回退控件。 |
| 重新打开右栏 | 恢复当前页面默认且符合条件的所有者，或用户明确选择的所有者；区分插件缺失与右栏关闭。 | 几何允许时才应用该所有者保留的偏好；不虚构持久化状态。 |
| 原生 Session 全屏 | Conversation 内遵循原生全屏优先；进入 Home 时暂停呈现。返回 Conversation 时恢复仍有效的显式模式，或按当前几何重新计算自动全屏。 | 逻辑状态和焦点意图独立于呈现；不能把临时不符合条件静默当作折叠。 |
| 缩放、拖动或窄屏抽屉 | 根据原生布局语义重新计算唯一符合条件的所有者；轨道放不下时使用经评审的窄屏呈现或可触达的重新打开操作。 | 保留各所有者首选宽度；安全取消或结束指针捕获，任何时刻不能有两个可交互右栏。 |
| Context 卸载、提供者缺失或注册被替换 | 清理 Context 注册、监听、待执行回调和轨道占用；原生 Session 符合条件时显示，否则为 `None`。 | 旧清理器只能释放自己的代次；保留 Session 状态，并将焦点移到可用的有名称控件。 |
| Renderer 重载 | 重新建立贡献，并按当前页面和可用所有者重新计算。 | 仅恢复已验证持久化契约覆盖的数据；否则显示真实默认状态或空状态。 |

在可见右栏标题区或其他始终可触达的位置设置有清晰名称的 Context/Session 切换器；具体控件仍是设计决策。向辅助技术暴露当前选择，让键盘焦点和可能提供的快捷键容易发现，并提供窄窗口可触达的等效控件。切换只改变呈现：不能创建、关闭或选择 Session。

过渡保持简短、可中断，并尊重减少动态效果偏好。先确定所有权再执行动画；不能让两个右栏同时接受指针、键盘焦点或无障碍遍历，卸载时取消待处理拖动和动画。关闭、切换或移除后，如果先前焦点目标不存在，焦点必须转移到可见且有名称的控件。

## 外观与导入

在现有设置入口中规划 Appearance Settings。模式、强调色、界面和等宽字体、字号、主题导入与重置均作为拟议控件；现有支持情况和范围见[主题系统](THEME_SYSTEM_SPEC.zh.md)。应用前预览变更，允许取消；校验失败时保留当前主题，拟议的数据限制由[导入规范](THEME_IMPORT_SPEC.zh.md)说明。

## 状态与无障碍

焦点、选中、错误、加载、空状态和禁用状态不得只依赖颜色或模糊表达。对话框和菜单必须可用键盘操作、可关闭并处于视口内。平台提供相关选项时尊重减少动态和透明效果；透明效果不可用或不适合时提供实色回退。
