# P1 Desktop 设计简报

[English](DESIGN_BRIEF.md) | 中文

## 摘要

设计一个平静、易读且具有 Workbench 识别度的桌面工作区，同时保留原生 Conversation 与 Session 工具。本设计用于评审，不授权修改生产界面。

## 设计方向

两套方向展示相同的 Home、Conversation、Session 右栏、Context、外观设置、导入及窄窗口状态：A 延续原生视觉语言；B 在保留原生组件识别度的基础上，增加克制的 Workbench 特征。B 是优先探索方向，尚未成为批准的最终方案。遵守上游[品牌规范](../../../../BRAND_GUIDELINES.zh.md)，不得暗示官方背书。

## 视觉原则

在有助于浏览的地方使用舒适间距，文件、Terminal 和技术输出保留紧凑行距。半透明材质仅用于部分导航、控制或浮层；长文本和高密度内容保持稳定的不透明表面。明暗外观、清晰焦点、减少透明效果和实色回退均属于设计范围。

## 范围与验收

展示 Home 与全局 Context、Conversation 与原生 Session 右栏、Conversation 与 Context、响应式让步、外观设置，以及含校验、预览、取消和恢复的主题导入流程。视觉原型可以模拟这些流程；必须标识模拟数据，不得暗示产品功能已经存在。

从原生兼容性、识别度、密度、可读性、性能、无障碍、自定义和实现成本比较两个方向。[右栏 ADR](../../GLOBAL_RIGHTBAR_ADR.zh.md) 仍待批准，本设计不代表其运行行为已经实现。

## 开发备注

本简报不授权生产界面实现。
