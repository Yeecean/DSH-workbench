# 外观设置规范

[English](APPEARANCE_SETTINGS_SPEC.md) | 中文

## 摘要

本设计为 Workbench 提议可恢复的外观设置。原生模式与文本、代码、终端独立字体设置已经存在；强调色控件和主题文件导入仍属提议。

<a id="controls"></a>
## 控件

现有主题插件将外观和字体控件注册到 General 设置区域（[client index.ts:630–650](../../../../packages/client/ui-theme/src/client/index.ts)）。原型应呈现下列易于理解的角色，但不能宣称未实现的操作已经可用。

| 控件 | 状态与拟议行为 |
|---|---|
| 主题模式 | 已有浅色、深色和跟随系统偏好；预览系统变化并显示选中状态。 |
| 强调色和表面 | 拟议有限调色板或经校验的自定义颜色；保留焦点和语义状态区分。 |
| UI 文本字体 | 已有文本字体族列表；展示可用性和原生回退。 |
| 代码与终端字体 | 已有独立字体族设置；说明并预览等宽对齐。 |
| 文本、代码、终端字号 | 已有独立的有界整数字号；文本字号标为 Conversation 内容字号，不称为全局界面缩放。 |
| 导入主题 | 拟议的文件选择和预览；设计原型中为模拟流程。 |
| 重置与撤销 | 拟议显式恢复默认和恢复上一主题操作，并明确显示结果。 |

原生字号范围为文本 10–22 px、代码 10–16 px、终端 10–20 px（[theme-settings.ts:24–63](../../../../packages/client/ui-theme/src/theme-settings.ts)）；现有证据不能证明存在独立的通用 UI 缩放或密度控件。长名称、中英文混排、数字、字符、字体缺失、高 DPI 和窄窗口均需评审。

<a id="preview-and-failure-states"></a>
## 预览和失败状态

确认前预览变更，或提供可明确撤销的即时预览。浅色和深色都要展示代表性的 Home、Conversation、Context 和 Terminal 内容；对实色回退及玻璃材质验证对比度、焦点和可读性。主题导入遵循[导入规范](THEME_IMPORT_SPEC.zh.md)：选择文件、校验、元数据与预览、确认、持久化和取消。

颜色、字体、文件或保存无效时，在相关控件旁显示可见错误；保持最后一次已提交的外观。明确区分不支持模糊、降低透明度和字体回退与保存失败。设置必须支持键盘操作，并向辅助技术传达选择、错误、预览和恢复操作。

<a id="acceptance"></a>
## 验收

使用相同内容比较原生延续型与轻度产品化型，包括实色与玻璃对比及窄窗口布局。验证主题切换不重置 Session，也不阻碍 Terminal 和 Files。若 P1 无法安全实现，主题文件导入最迟在 P1.1 交付；导出和高级管理可后续评估。本提议尚未针对 Desktop 应用测试。
