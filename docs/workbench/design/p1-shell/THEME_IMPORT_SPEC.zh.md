<a id="draft-file-model"></a>
## 文件模型草案

评估使用 UTF-8 JSON，包含固定格式标记、整数 Schema 版本、有长度限制的主题 ID 和显示名、可选作者或来源文本、浅色或深色基础，以及明确允许的少量语义颜色和字体选项。以下文件只是示意，并非现有格式：

```json
{
  "format": "dsh-workbench-theme",
  "version": 1,
  "id": "quiet-blue",
  "name": "Quiet blue",
  "base": "light",
  "colors": { "accent": "#315AC4", "surface": "#FFFFFF" },
  "fonts": { "text": "Segoe UI", "terminal": "Consolas" }
}
```

具体允许的字段和映射需要主题归属者评审；形状、间距和材质字段只能在受支持且有界时加入。不能假设原生 CSS 变量、插件图标文档或自定义主题 ID 均可安全导入或被原生系统持久选择。现有注册契约用于受信任的插件代码（[ui-theme client index.ts:72–96, 252–265](../../../../packages/client/ui-theme/src/client/index.ts)）。

<a id="validation-boundary"></a>
## 校验边界

仅导入数据：拒绝脚本、HTML、样式表、CSS 声明、URL、动态模块、插件代码和任意图标标记。Token 名称必须属于明确白名单，颜色必须按严格格式解析；字体名称按原生规则规范化并限制长度（[theme-settings.ts:155–168](../../../../packages/client/ui-theme/src/theme-settings.ts)），不得通过文件内 URL 获取字体。

解析前限制字节数并要求 UTF-8。限制集合数量、嵌套、ID／名称／来源长度、数值范围和字符串；拒绝重复键与不支持的 Schema 版本。版本 1 对未知字段给出带字段路径的清晰错误并拒绝；未来兼容策略必须随版本明确。最终限制需要实现评审和测试。

解析基础主题后检查必要的前景／背景及控件／焦点对比度，包括实色回退。无法访问的组合应拒绝，或在确认前明确展示安全修正。文件不得保存凭据、文件路径、Session 内容或其他私人用户数据。

<a id="preview-apply-and-recovery"></a>
## 预览、应用和恢复

选择文件 → 解析校验 → 显示名称、来源和基础模式 → 不持久化预览 → 确认或取消 → 应用并持久化。预览不得写入设置或改变 Session 状态；取消或关闭时恢复原外观。字体不可用时明确提示并展示回退效果。

确认时按当前状态再次校验；可见更新和持久写入必须组成可恢复事务，明确处理并发设置变更；校验、渲染或持久化失败时保留先前已提交的主题。崩溃或重载后必须得到完整有效的旧主题或新主题，不能留下部分 Token。提供恢复默认和回退上一主题操作。

导出和管理可在 P2 及以后进行，不得延误明确要求的导入。导出设计必须排除个人路径、凭据、Session 数据及不必要的元数据；由于原生内置偏好写入器不持久化自定义 ID，实际持久化设计仍待确认。

<a id="acceptance"></a>
## 验收

覆盖有效的浅色／深色文件、未知字段或版本、格式错误的 JSON、重复键、超大输入、不安全 CSS 或 URL、字体缺失、对比度失败、取消、并发修改、存储失败、崩溃恢复及重启。每次导入失败后均须确认原外观和原生 Session、Terminal、Files 仍可用。这些检查属于计划，尚未运行。
